# TunerIPTV updates

Tämä julkinen repository sisältää vain TunerIPTV:n päivitysjakelun tiedostot.

- `latest.json` kertoo sovellukselle uusimman version.
- `TunerIPTV-latest.apk` lisätään ensimmäisen OTA-julkaisun yhteydessä.
- `index.html` toimii yksinkertaisena päivityssivuna.

Varsinainen TunerIPTV-lähdekoodi ja API-avaimet eivät kuulu tähän repositoryyn.

## Nykyinen tila

OTA-päivitysjärjestelmän pohja on valmis versiolle **0.5.19-easy-updates**.  
Ensimmäinen sovelluksen sisältä ladattava päivitys julkaistaan versiosta **0.5.20** alkaen.
